# 超级马里奥 · 像素冒险

单文件 HTML 横版闯关游戏的 Android 封装版，WebView 加载本地资源，**完全离线可玩**，无任何网络权限。

## 下载安装

直接下载 `super-mario.apk`（约 153 KB），在手机上允许「未知来源」安装即可。

- 无需联网、无广告、无内购、不申请任何敏感权限
- 横屏体验最佳，竖屏也可玩（按键在画面下方）

## 玩法

- 键盘：方向键 / AD 移动，空格或 W 跳跃，Shift 奔跑
- 手机：屏幕虚拟按键（← → 奔跑 跳）
- 踩敌人得分，顶问号砖块出金币，抵达旗杆过关
